Host metrics → tags

The reverse bridge: pull host metrics (CPU, memory, disk, ports, uptime) into osodb as osq.* tags — usable by alarms, the HMI, the historian and any gateway, exactly like a sensor. Uses osquery when installed, else /proc. Continuous import: set OSO_OSQUERY_METRICS=1

ATC configuration

Drop this into osquery.conf.d/ (or click Install ATC config above) so a host osquery daemon exposes oso_tags. It reads a standalone read-only snapshot, so queries never touch the real-time path.
